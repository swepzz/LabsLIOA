# Задание 4. Оценка сложности поиска

В функции `countOccurrences()` в начале проверяется, является ли текущий узел пустым (`if (root == NULL)`). Затем искомое значение сравнивается со значением текущего узла. В зависимости от результата функция переходит в левое или правое поддерево. На каждом шаге выполняется постоянное количество операций — O(1).

Общая сложность зависит от высоты дерева h и составляет O(h). Для сбалансированного дерева сложность равна O(log n), а для вырожденного в цепочку — O(n).

Вывод: в данной программе сложность поиска составляет O(log n) для сбалансированного дерева и O(n) в худшем случае, поскольку балансировка не предусмотрена.
