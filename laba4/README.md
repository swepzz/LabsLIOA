## Дополнительное задание

Для дерева с повторяющимися значениями при подсчёте числа вхождений заданного значения дополнительно определять и выводить уровень каждого его вхождения. Уровень корня — 0, при переходе к дочернему узлу уровень увеличивается на 1.

Задание реализовано в [`laba4_task2/laba4_task2.cpp`](laba4_task2/laba4_task2.cpp). Функция `countOccurrences()` принимает текущий уровень, выводит его для каждого найденного совпадения и возвращает общее число вхождений. Поиск начинается вызовом `countOccurrences(root, value, 0)`. Если значение отсутствует, программа выводит число вхождений 0 и сообщение о том, что значение не найдено.

Например, после ввода чисел `5 3 7 5 5` (завершение ввода — `-1`) поиск значения `5` покажет уровни `0`, `2`, `3` и число вхождений `3`.
