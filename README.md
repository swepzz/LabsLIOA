# Лабораторная работа №5

Определение характеристик неориентированного графа по матрице смежности: количества рёбер, степеней вершин, изолированных, концевых и доминирующих вершин.

Программа: [`task1/task1/task1.cpp`](task1/task1/task1.cpp). Решение Visual Studio: [`task1/task1.sln`](task1/task1.sln).

## Дополнительное задание

Добавить возможность задавать вероятность появления ребра при случайной генерации графа.

После количества вершин пользователь вводит вероятность `p` от `0` до `1` включительно. Дробная часть вводится через точку, например `0.25` — вероятность 25%. Для каждой пары различных вершин ребро создаётся с заданной вероятностью. Матрица остаётся симметричной, петли не создаются.

- При `p = 0` рёбер нет.
- При `p = 1` каждая пара различных вершин соединена ребром.
- При `p = 0.5` вероятность ребра составляет 50%, как в исходной версии программы.

Некорректная вероятность отклоняется с сообщением об ошибке. Вероятность задаётся для каждой пары вершин и не гарантирует точную долю рёбер в конкретном случайном графе.

Например, для `4` вершин и `p = 1` программа создаст полный граф с `6` рёбрами; при `p = 0` — граф с `0` рёбер.
